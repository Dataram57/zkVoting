# Plans for upgrading this project

### Application

- Users no longer rely on the web app and use traditional executables.

### Cryptography

- Removal of the trusted setup.
- Quantum-Resistant cryptography
- More suitable hashing functions (used for deterministic IDs and mapping them to other hashing domains)

### Complete Zero-Trust approach to the server

- Checking if the user has already cast a vote.

### Commercialization

- Polls are hosted on IPFS.

### Decentralization

- Polls are run on public or private blockchain.

### Increasing limits

- Polls are using greater Merkle tree height.
- New cryptosystem enables proving valid votes without sending all of them to each user.
